# 🔥 Nova Shield — AI-Ready Cybersecurity API Gateway (Golang)

Nova Shield is a **high-performance reverse proxy and security gateway** built in Golang.
It protects backend APIs from malicious traffic using **rate limiting, WAF, IP blocking, and real-time monitoring**.

---

# 🚀 Features

## 🔐 Security Layer

* ✅ Rate Limiting (per IP + per route)
* ✅ Web Application Firewall (WAF)

  * SQL Injection Detection
  * XSS Detection
  * Command Injection Protection
* ✅ IP Blacklisting

## ⚡ Performance

* ✅ Handles **5,000–10,000 requests under load**
* ✅ Optimized for high concurrency
* ✅ Connection pooling & worker-based load handling

## 📊 Monitoring

* ✅ Real-time request tracking
* ✅ Logs for blocked requests
* ✅ Frontend dashboard (React)

---

# 🏗️ Architecture

```
Client (Frontend / Attack Script)
        ↓
🚀 Nova Shield Proxy (Port 9090)
 ├── Rate Limiter
 ├── WAF
 ├── Blacklist
 ├── Logger
        ↓
🏦 Backend API (Port 8080)
```

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```
git clone <your-repo-url>
cd nova-shield
```

---

## 2️⃣ Install Go Dependencies

```
go mod tidy
```

---

# ▶️ How to Run the Project

---

## 🔹 Step 1 — Run Backend Server

Open Terminal 1:

```
cd backend
go run server.go
```

👉 Runs on:

```
http://localhost:8080
```

---

## 🔹 Step 2 — Run Proxy Server

Open Terminal 2:

```
cd ..
go run cmd/proxy/main.go
```

👉 Runs on:

```
http://localhost:9090
```

---

## 🔹 Step 3 — Run Frontend Dashboard

Open Terminal 3:

```
cd frontend
npm install
npm run dev
```

👉 Open in browser:

```
http://localhost:5173
```
